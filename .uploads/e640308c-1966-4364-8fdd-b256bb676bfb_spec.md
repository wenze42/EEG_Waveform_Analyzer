# 实验3-负反馈放大器 文档校对与仿真验证 - 需求规范

## Overview
- **Summary**: 依据 PDF 实验指导书校对主实验报告 docx，删除其仿真部分并插入电路图；调用 LTspice MCP 复现仿真，依据真实仿真值修正仿真报告中的数值。
- **Purpose**: 确保实验报告内容/数据表格与指导书一致，仿真结果数值准确。
- **Target Users**: 实验报告撰写者（学生）。

## Goals
- 校对 `实验3-负反馈放大器.docx` 的正文与数据表格，使其与 PDF 指导书一致。
- 从主文档中删除"LTspice仿真结果与分析"整节。
- 在主文档"电路图"处插入可直接使用的电路图（sch_exp3_fb.png）。
- 用 LTspice MCP 重新运行 5 个仿真，核验并修正仿真报告中的数值。

## Non-Goals
- 不修改主文档"十、思考题"部分。
- 不修改仿真报告的结构、原理描述、结论措辞（仅修正仿真数值与由数值推导的结论）。
- 不重新生成仿真电路图或波形图。
- 不填写主文档中需学生实测的数据表（保留空白实测行）。

## Background & Context
- PDF 指导书规定了实验电路、测量项、注意事项与参考静态工作点（Vb2≈3V、Vc2≈7.6V、Vb1≈1V、Vc1≈8.4V）。
- 主文档当前包含两节"六"：六、需要测量的数据表；以及末尾的"六、LTspice仿真结果与分析"（含 4 张仿真波形图）。
- 主文档仿真节中 Rof 写为 -58.5Ω，与 LTspice 实测 +84.3Ω 不符；幅频截止频率也与仿真略有偏差。
- LTspice 仿真文件夹含 5 个 .cir 网表与对应 .raw 结果，以及 5 张 png（sch_exp3_fb.png 为原理图，fig1~4 为波形）。

## Functional Requirements
- **FR-1**: 主文档正文（实验目的、仪器、原理、步骤、注意事项）与 PDF 指导书一致；数据表格列项与 PDF 测量项一致。
- **FR-2**: 主文档中"LTspice仿真结果与分析"整节（含标题、正文、表格、图片）被完全删除，且不残留空段。
- **FR-3**: 主文档"四、电路图"处插入 `LTspice仿真/sch_exp3_fb.png`，替换原有占位文字。
- **FR-4**: 主文档"十、思考题"逐字保持不变。
- **FR-5**: 仿真报告中所有仿真数值与 LTspice MCP 复现结果一致（静态工作点、Avf/Fv、幅频特性 fL/fH/增益、Rif、Rof）。
- **FR-6**: 仿真报告中由数值推导的结论（如"Rof≈+84.3Ω"）随数值同步修正。

## Non-Functional Requirements
- **NFR-1**: 修改后 docx 可正常打开，图片显示正常，无损坏。
- **NFR-2**: 保留原有排版（字体、段落、表格样式）。

## Constraints
- **Technical**: 仅通过编辑 docx 内部 XML（unpack/edit/pack）修改，不破坏样式。
- **Dependencies**: LTspice 仿真需通过 mcp_ltspice / mcp_ltspice-mcp 完成。

## Assumptions
- 主文档数据表格的"实测值"留空（学生实验后填写），表格结构本身正确即可。
- 仿真报告中已嵌入的波形图与外部 fig1~4.png 一致，无需替换图片。
- 仿真报告中 image2（LTspice 原理图）即 sch_exp3_fb.png。

## Acceptance Criteria

### AC-1: 主文档正文与数据表符合 PDF
- **Type**: `rule`
- **Given**: 主文档已修改
- **When**: 比对正文/数据表列项与 PDF 指导书
- **Then**: 实验步骤、注意事项关键参数、数据表列项与 PDF 一致
- **Pass Condition**: 逐项核对无遗漏或矛盾
- **Evidence**: 修改后的主文档 pandoc 文本输出

### AC-2: 主文档仿真节已删除
- **Type**: `rule`
- **Given**: 主文档已修改
- **When**: 检索文档文本
- **Then**: 不出现"LTspice仿真结果与分析"标题及该节任何内容
- **Pass Condition**: pandoc 输出中无"LTspice仿真结果"字样
- **Evidence**: 修改后的主文档 pandoc 文本输出

### AC-3: 主文档电路图已插入
- **Type**: `rule`
- **Given**: 主文档已修改
- **When**: 检查"四、电路图"段与 word/media
- **Then**: 该段包含 sch_exp3_fb.png 图片，且 media 中存在该图片
- **Pass Condition**: media 含对应图片且"电路图"段有 drawing 引用
- **Evidence**: docx zip 中 word/media 列表 + document.xml 片段

### AC-4: 思考题未修改
- **Type**: `rule`
- **Given**: 主文档已修改
- **When**: 比对"十、思考题"原文与修改后文本
- **Then**: 思考题题目与答案逐字相同
- **Pass Condition**: diff 无差异
- **Evidence**: 修改前后思考题文本对比

### AC-5: 仿真报告数值与 LTspice 一致
- **Type**: `rule`
- **Given**: 仿真报告已修改
- **When**: 比对仿真报告数值与 LTspice MCP 复现值
- **Then**: 静态工作点、Avf/Fv、fL/fH/增益、Rif、Rof 均与仿真一致（误差在合理舍入范围内）
- **Pass Condition**: 逐项核对通过，尤其 Rof 为 +84.3Ω 而非负值
- **Evidence**: LTspice run_code 输出 + 修改后仿真报告文本

### AC-6: docx 文件完整性
- **Type**: `rule`
- **Given**: 修改后的两个 docx
- **When**: 用 zipfile 打开并校验
- **Then**: 两个 docx 均可正常解析，无结构损坏
- **Pass Condition**: zipfile 校验通过，document.xml 可解析
- **Evidence**: Python zipfile 校验输出
